# IDD-0009.spec-model-discovery

## Intent

Show models available from each configured LLM server and the capabilities relevant to agent use.

## Related Specifications

Related: IDD-0005, IDD-0006.

## Behavior

The view groups results by server and displays model name, image support, function-calling support, modification time, size, and per-server errors. A filter field narrows the displayed models by model name, ignoring letter case. Server errors and empty-server states remain visible while filtering; a server that has models but no matching model indicates that no models match the filter.

## Durable Architecture And Constraints

Model capability information is discovered from configured servers.

## Non-Goals

This surface does not download, delete, or train models.

## Acceptance Criteria

- A server with no models, a server error, and no configured servers are distinguishable states.
- Capability indicators are available for each discovered model.
- Entering a filter shows only matching model names, regardless of letter case, and makes an empty filtered result distinguishable from a server with no models.

## Verification

Automated coverage verifies result grouping, capability interpretation, unavailable-server reporting, and case-insensitive model-name filtering. Manual verification confirms that the filter updates the displayed models and preserves server errors and empty-server states.
