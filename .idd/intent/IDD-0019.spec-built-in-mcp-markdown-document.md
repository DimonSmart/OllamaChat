# IDD-0019.spec-built-in-mcp-markdown-document

## Intent

Provide the single opt-in built-in MCP server for structured reading and targeted editing of a bound Markdown document or book.

## Related Specifications

Related: IDD-0007, IDD-0008.

## Behavior

The server works directly with a real Markdown source, exposes document context, hierarchical outline references, headings, sections, individual items such as paragraphs, search, and Markdown export. Stateful cursors support incremental reading of large documents. Ordered targeted edits can replace, insert before or after, remove, split, or merge items addressed through semantic pointers or item positions. Editing and reloading preserves the resulting Markdown source as the authoritative document representation.

## Durable Architecture And Constraints

Editing is scoped to the document bound to the MCP session. A pointer uniquely identifies an item in the currently parsed document. An edit using a pointer that no longer exists fails clearly; after structural edits, an agent can re-read the affected section to obtain current pointers. Pointers are not promised to remain stable across arbitrary structural edits.

## Non-Goals

The server does not edit files outside its bound document and does not maintain a parallel JSON knowledge-book representation.

## Acceptance Criteria

- A cursor can be created, resumed, inspected, and reset.
- Hierarchical outline navigation and individual paragraph addressing work within the same document.
- Replace, insert-before, insert-after, remove, split, and merge operations update the bound document predictably.
- Large documents can be read incrementally.
- Search and export reflect the bound document.
- An edited Markdown file can be reloaded and yields valid current pointers.
- A stale or missing pointer fails clearly, and re-reading yields updated pointers after structural edits.

## Verification

Automated coverage verifies hierarchical navigation, paragraph addressing, cursor progression over large documents, all targeted edit operations, stale-pointer failures, direct Markdown persistence and reload, current pointers after reload, document scoping, search, and export.
