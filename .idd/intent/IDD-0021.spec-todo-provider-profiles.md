# IDD-0021.spec-todo-provider-profiles

## Intent

Let users manage reusable Todo Provider configuration profiles for saved-agent planning behavior.

## Related Specifications

Related: IDD-0001, IDD-0005.

## Behavior

Users can create, search, edit, and delete named Todo Provider profiles. A profile may provide custom instructions, an optional todo-list message template, and whether the todo-list message is suppressed. Empty optional text values defer to framework defaults. A saved agent may optionally select one profile; that selection makes the Todo Provider available for the agent's sessions.

## Durable Architecture And Constraints

Todo Provider profiles are application-owned persisted models and do not expose Microsoft Agent Framework runtime types or delegates. The saved-agent runtime materializes a selected profile into its provider configuration without persisting runtime types or delegates. Selecting a profile makes it eligible for the saved agent's optional TODO-completion behavior; the saved agent owns whether that behavior is enabled.

## Acceptance Criteria

- Profile names are required and unique without regard to case.
- Optional instructions and message templates preserve multiline custom content; a template may contain the `{todos}` placeholder.
- Deleting a profile requires confirmation.
- The profiles catalog is available from the main navigation near reusable agent configuration.

## Verification

Automated coverage verifies profile CRUD persistence, timestamp behavior, name validation, and preservation of multiline optional content. Manual verification confirms search and the create/edit/delete interactions.
