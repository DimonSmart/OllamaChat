# IDD-0021.spec-todo-provider-profiles

## Intent

Let users manage reusable Todo Provider configuration profiles for future agent planning behavior.

## Related Specifications

Related: IDD-0001, IDD-0005.

## Behavior

Users can create, search, edit, and delete named Todo Provider profiles. A profile may provide custom instructions, an optional todo-list message template, and whether the todo-list message is suppressed. Empty optional text values defer to the framework defaults in a future runtime integration.

## Durable Architecture And Constraints

Todo Provider profiles are application-owned persisted models and do not expose Microsoft Agent Framework runtime types or delegates. Profile management does not alter agent execution, enable the Todo Provider, or bind profiles to agent templates.

## Acceptance Criteria

- Profile names are required and unique without regard to case.
- Optional instructions and message templates preserve multiline custom content; a template may contain the `{todos}` placeholder.
- Deleting a profile requires confirmation.
- The profiles catalog is available from the main navigation near reusable agent configuration.

## Verification

Automated coverage verifies profile CRUD persistence, timestamp behavior, name validation, and preservation of multiline optional content. Manual verification confirms search and the create/edit/delete interactions.
