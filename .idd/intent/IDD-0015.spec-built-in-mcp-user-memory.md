# IDD-0015.spec-built-in-mcp-user-memory

## Intent

Provide an opt-in built-in MCP server through which an agent can explicitly maintain durable user preferences and useful learned facts.

## Related Specifications

Related: IDD-0007, IDD-0008, IDD-0010.

## Behavior

The server provides unsurprising, explicit operations to read, set, list, delete, and clear user preference values. Reading is side-effect free and never elicits input or modifies persistence. If interactive elicitation is supported, it is a separate, explicitly named operation.

Configured preference definitions remain suitable for settings such as language, time zone, verbosity, editor, and measurement system. Learned facts are stored as generic memory entries without requiring a predefined field. Agents can remember facts, list and search memories using durable identifiers, and forget an individual memory.

## Durable Architecture And Constraints

Preferences and memories are scoped to the relevant user context and persist across conversations, service recreation, and application restarts. Clearing preference values preserves their configured field definitions. Updating an existing preference replaces its value; forgetting a memory does not affect unrelated entries.

## Non-Goals

The server does not expose data belonging to another user context. Textual memory search is sufficient; semantic or vector search is not required.

## Acceptance Criteria

- An agent can explicitly store, retrieve, replace, and delete one preference value.
- Listing preferences returns configured definitions together with their current values.
- Clearing preferences removes stored values while retaining definitions.
- Reading a missing preference has no side effects and does not initiate elicitation.
- An agent can remember arbitrary user facts, list or textually search them, and forget one by identifier.
- Preferences and memories remain available after the owning service is disposed and recreated.

## Verification

Automated coverage verifies scoped parsing and access, side-effect-free reads, preference create/replace/delete/reset behavior, generic memory remember/list/search/forget behavior, and durable round trips across service recreation.
