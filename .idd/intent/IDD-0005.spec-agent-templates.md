# IDD-0005.spec-agent-templates

## Intent

Let users manage reusable agent definitions that combine instructions, optional model settings, tool access, and retrieval files.

## Related Specifications

Related: IDD-0001, IDD-0004, IDD-0006, IDD-0007, IDD-0021, IDD-0022.

## Behavior

Users create, search, edit, delete, and restore templates. A template can define identity, summary, instructions, optional model tuning, tool selection, MCP-server bindings, attached retrieval files, and optional Todo Provider and Agent Mode Provider profiles.

When a saved agent is run, each selected provider profile configures that agent's runtime provider for the session. An unselected provider remains unavailable; deleting a selected profile leaves the agent's saved selection intact but that provider is unavailable until the selection is changed. Provider state is preserved by the agent session. No automatic continuation or todo-completion loop is enabled by this selection.

## Durable Architecture And Constraints

Template-specific values may defer to application defaults when omitted.

## Non-Goals

This surface does not configure server connections or author workflow source.

## Acceptance Criteria

- Required agent identity and instructions are validated.
- Attached files expose indexing state.
- Restoring shipped templates preserves custom templates.
- Each provider selection is optional and offers the available profiles plus no selection.
- A selected Todo Provider profile exposes todo management to the running agent using its saved configuration.
- A selected Agent Mode Provider profile exposes its saved modes and default mode to the running agent.

## Verification

Automated coverage verifies template validation, model selection, tool bindings, retrieval attachments, provider-profile propagation, and restoration semantics. Manual verification confirms that a selected profile retains todo or mode state within a chat session.
