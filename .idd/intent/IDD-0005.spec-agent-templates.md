# IDD-0005.spec-agent-templates

## Intent

Let users manage reusable agent definitions that combine instructions, optional model settings, tool access, and retrieval files.

## Related Specifications

Related: IDD-0001, IDD-0004, IDD-0006, IDD-0007, IDD-0021, IDD-0022.

## Behavior

Users create, search, edit, delete, and restore templates. A template can define identity, summary, instructions, optional model tuning, tool selection, MCP-server bindings, attached retrieval files, and optional Todo Provider and Agent Mode Provider profiles.

When a saved agent is run, each selected provider profile configures that agent's runtime provider for the session. An unselected provider remains unavailable; deleting a selected profile leaves the agent's saved selection intact but that provider is unavailable until the selection is changed. Provider state is preserved by the agent session. A saved agent may opt in to automatic TODO completion with a positive maximum iteration count. The opt-in is valid only when both provider profiles are selected and the selected mode profile contains the exact runtime mode name `execute`; autonomous continuation is restricted to that mode. In all other cases, a user message runs once and stops.

## Durable Architecture And Constraints

Template-specific values may defer to application defaults when omitted.

## Non-Goals

This surface does not configure server connections or author workflow source.

## Acceptance Criteria

- Required agent identity and instructions are validated.
- Attached files expose indexing state.
- Restoring shipped templates preserves custom templates.
- Each provider selection is optional and offers the available profiles plus no selection.
- A selected Todo Provider profile exposes todo management to the running agent using its saved configuration.
- A selected Agent Mode Provider profile exposes its saved modes and default mode to the running agent.
- The saved-agent editor exposes the TODO-completion opt-in and maximum autonomous iterations, defaults them to disabled and 10, and prevents saving an enabled configuration without the required profiles, an `execute` mode, and an iteration count from 1 through 100.
- An enabled saved agent continues a user-triggered run only while the current session mode is exactly `execute` and TODOs remain, stopping when TODOs complete, the configured limit is reached, or the run is cancelled. Reaching the limit leaves the session usable and preserves remaining TODOs.

## Verification

Automated coverage verifies template validation, model selection, tool bindings, retrieval attachments, provider-profile propagation, restoration semantics, and the enabled/disabled TODO-completion invariants. Manual verification confirms that a selected profile retains todo or mode state within a chat session, plan mode does not continue automatically, and execute mode completes TODOs up to the configured limit while the session-state panel refreshes after the run.
