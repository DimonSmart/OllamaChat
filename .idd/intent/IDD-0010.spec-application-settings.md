# IDD-0010.spec-application-settings

## Intent

Let users set application-wide defaults for chat, participant naming, voice input, retrieval behavior, and creation of local workspaces.

## Related Specifications

Related: IDD-0001, IDD-0004, IDD-0005, IDD-0024.

## Behavior

Users choose chat-history processing, default messages, participant display names, voice-input enablement and model, embedding chunking settings, an application-wide Workspaces root, and Saved Chats storage and automatic-saving settings. The Workspaces root is an absolute local directory used as the parent when a user creates a workspace from an agent launch screen. Existing installations use a cross-platform default below the user profile, and the root may be created when it is first needed. Voice transcription accepts an audio upload and returns text or a user-facing error.

## Durable Architecture And Constraints

Settings act as defaults for agent templates that do not provide an override. The default RAG minimum relevance score applies only to agents using built-in RAG defaults; RAG Provider Profiles can set their own threshold or disable threshold filtering.

The Workspaces root is persisted application-wide. It is not a selected session workspace and does not cause a workspace path to be persisted into an agent template or File Access Provider profile.

The Saved Chats root has a cross-platform default below the user profile. Automatic saving defaults to enabled; title-generation settings are persisted for future use but do not require an LLM invocation.

## Non-Goals

This surface does not edit individual agent instructions.

## Acceptance Criteria

- Settings persist and affect subsequent applicable sessions.
- The Workspaces root persists, loads safely from settings saved before it existed, and supplies the parent directory for newly created workspaces.
- Voice input can be disabled without affecting text chat.
- Saved Chats settings load safely from settings saved before they existed.
- Invalid or oversized audio receives a clear error response.

## Verification

Automated coverage verifies settings persistence, including backward-compatible loading and defaulting of the Workspaces root, history modes, and voice-input validation.
