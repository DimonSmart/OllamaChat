# IDD-0004.spec-vector-search

## Intent

Enable retrieval over files attached to an agent and show index progress and search results.

## Related Specifications

Related: IDD-0001, IDD-0005, IDD-0010.

## Behavior

Users select an agent, see its attached-file and indexing state, submit a query, and receive ranked content segments with file identity and score. The same agent-bound knowledge is available to the runtime chat agent as retrieval context.

When indexed knowledge exists, chat retrieval is enabled automatically. Agents that support function calling can search their attached knowledge on demand with focused queries and may search more than once in a run. Agents without function calling receive retrieval before an invocation, using a short recent conversation context. An agent without indexed knowledge has no knowledge-search capability.

## Durable Architecture And Constraints

Retrieval is scoped to the selected agent's attached files. Search returns only
content whose relevance meets the configured retrieval threshold; a query with
no sufficiently relevant attached content returns no results. This is a normal
outcome and does not add unrelated knowledge to chat context.

Retrieved file content is untrusted reference data, not agent instructions. The runtime keeps retrieval separate from the agent's instructions and does not expose a way for a model to select another agent's knowledge source.

## Non-Goals

This surface does not manage general-purpose document libraries.

## Acceptance Criteria

- Search results identify their source file and relevance score.
- An unrelated query returns no knowledge results once the configured relevance
  threshold is not met.
- Indexing state remains visible while processing is in progress.
- Chat retrieval does not use files from unrelated agents.
- Function-capable agents do not retrieve solely because a user message was sent; they can invoke knowledge search when it is relevant.
- Agents without function calling continue to receive relevant attached knowledge during chat.
- Retrieved knowledge is treated as untrusted reference data rather than instructions.

## Verification

Automated coverage verifies indexing recovery, agent isolation, ranked retrieval behavior, automatic retrieval-mode selection, and the absence of knowledge search for agents without indexed files. Manual verification confirms that a function-capable agent can answer a unique fact from an attached file after an on-demand knowledge search and does not search for a greeting.
