# IDD-0001.spec-agentic-chat

## Intent

Provide an interactive chat surface for running a selected agent or saved workflow.

## Related Specifications

Related: IDD-0002, IDD-0004, IDD-0005, IDD-0007, IDD-0009, IDD-0010.

## Behavior

Users select an available agent or workflow, supply required inputs, and exchange messages. Responses stream into the transcript; users can cancel an active response and copy the conversation as text, Markdown, or HTML. The transcript exposes assistant reasoning and tool activity when supplied by the runtime. A direct-agent conversation with available runtime session state exposes a compact, initially collapsed Session state panel beside the conversation copy action. The panel shows the current runtime mode and/or TODO list when those capabilities are available, including an empty TODO list; it refreshes after session creation, completed runs, and conversation reset. Workflow conversations do not present an ambiguous combined session state.

## Durable Architecture And Constraints

Conversation execution supports both direct agents and workflow-based agents.

Session-state display is a read-only projection of the active direct conversation's runtime session. Agent-session state remains the sole owner of modes and TODOs; saved-agent configuration, transcript/tool history, and UI state do not substitute for it.

## Non-Goals

This surface does not define how agents, workflows, servers, or tools are authored.

## Acceptance Criteria

- A valid selection can receive a user message and return streamed output.
- Cancellation leaves the conversation in a usable state.
- Users can export the displayed transcript in each offered format.
- A direct conversation with a mode or TODO capability can reveal its current session state without opening a separate TODO page.
- A direct conversation with a TODO capability distinguishes an empty list from an unavailable capability, and a new conversation does not display TODOs from the previous session.
- A workflow conversation does not select or aggregate a participant's session state.

## Verification

Automated coverage verifies streaming, cancellation, transcript state, export formatting, and runtime session-state projection. Manual verification confirms session-state updates across runs and resets.
